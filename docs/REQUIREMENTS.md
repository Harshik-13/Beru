# Requirements — Beru

## Student-Facing Interface

- WhatsApp-first / WhatsApp-only for normal usage.
- No separate web/mobile app required for students.

## Core Features

1. WhatsApp interaction
2. Secure onboarding
3. College portal integration (read-only)
4. Academic profile extraction
5. Attendance retrieval
6. Attendance snapshots with provenance/timestamps
7. Attendance simulations
8. Weekly timetable image upload/extraction/confirmation
9. Daily briefing at student-configured time
10. Natural-language questions and follow-ups
11. Announcements/assignments/notes/timetable changes (where supported)
12. Secure authentication and authorization
13. Auditability
14. Reliable background jobs
15. Multi-user data isolation

## Rollout

1. **Personal Alpha** — Harshik pilots the system personally.
2. **Controlled Pilot** — Selected VNR VJIET Cybersecurity students.
3. **Broader Platform** — College-wide later.
